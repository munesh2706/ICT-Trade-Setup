# ICT Framework Reference and Source Register

## Primary source

The methodology authority for this project is Michael J. Huddleston (The Inner Circle Trader) and his original teaching material.

- Official ICT website and mentorship/core content: https://www.theinnercircletrader.com/
- ICT mentorship core content entry point: https://www.theinnercircletrader.com/index.html

The official material must be consulted directly before encoding exact rules. Secondary summaries are not substitutes for the original lesson.

## Methodology note

ICT is a broad body of teaching with multiple concepts, mentorship years, and named trade models. There is no basis to assume that every ICT model uses the same entry sequence or that every concept is mandatory in every model.

Accordingly:
- Keep each named model separate.
- Attribute each rule to a primary lesson and version.
- Preserve alternate variants rather than merging them.
- Label coding interpretations as engineering assumptions when the source does not specify a machine-readable threshold.
- Do not claim that a secondary site's simplified summary is an official ICT rule.
